# Code Inspector

أداة خفيفة لفحص وتحليل الشفرات البرمجية الساكنة، متخصصة في معالجة أربع لغات أساسية:

* **Python**
* **JavaScript**
* **CSS**
* **HTML**

---

## الهدف من المشروع

تجميع أدوات الفحص والتنسيق المتعددة في منصة واحدة بسيطة، للتحقق من صحة الصياغة النحوية، كشف الأخطاء التنسيقية والقواعدية، وتقليل المشاكل البرمجية قبل تشغيل الكود.

---

## الأدوات المستعملة

* **Vite:**
   بناء وتطوير الواجهة الأمامية بسلاسة وخفة.

* **ESLint:**
  فحص شفرات JavaScript وكشف الأخطاء والممارسات غير المستحسنة.

* **Prettier:**
   إعادة تنسيق الشفرات البرمجية وتوحيد مظهرها تلقائياً.

* **HTML-Validate:**
   التحقق من صحة بنية وسوم HTML ومطابقتها للمعايير القياسية.

* **PurgeCSS:**
   التعرف على قواعد CSS غير المستعملة وتصفيتها.

* **CSSLint:**
   فحص صياغة ملفات CSS واكتشاف الأخطاء القواعدية.

* **Semgrep:**
   مطابقة الأنماط وتتبع عيوب الصياغة والثغرات الهيكلية.

* **Python AST & Flask:**
   استخراج بنية بايثون النحوية وبناء خادم الويب للربط بين الواجهة والأدوات.

---

## تقرير المخرجات

يُرجع الخادم تقريراً محدداً وموحداً لكل عملية فحص بصيغة `JSON` يتضمن العناصر التالية:

* **بيانات الفحص:**
  اسم الأداة المُفحص بها (مثل ESLint أو HTML-Validate) واللغة المستهدفة.

* **حالة الشفرة (`is_valid`):**
  قيمة منطقية تُحدد ما إذا كان الكود سليماً أو يحتوي على تنبيهات.

* **مجموع الملاحظات (`total_issues`):**
  العدد الإجمالي للأخطاء التنسيقية أو القواعدية المكتشفة.

* **تفاصيل الخلل:** قائمة لكل نقطة تتضمن:
  * **الموقع:** رقم السطر والعمود بدقة.
  * **درجة الخطورة:** تصنيف الخلل إلى (خطأ / تنبيه).
  * **الرسالة:** نص مباشر يشرح طبيعة المشكلة.
  * **معرّف القاعدة:** رمز القاعدة البرمجية المكسورة ليسهل تصحيحها.
